# E-Invoice Products

| Category | Tool / Service | What it does |
| --- | --- | --- |
| Validation | Peppol Validator | Validates UBL / Peppol BIS 3.0 against EN 16931 and Peppol rules |
| | Factur-X Validator | Validates Factur-X / CII, including ZUGFeRD |
| | ZUGFeRD Validator | Validates ZUGFeRD invoices and their profiles |
| | ZUGFeRD Profile Checker | Identifies the ZUGFeRD profile and checks XML compliance |
| | VAT Number Validator | Validates VAT numbers via VIES |
| | SIRET Validator | Validates French SIRET numbers |
| Viewing | Peppol Invoice Viewer | Displays UBL / Peppol invoices in an easy-to-read format |
| | ZUGFeRD / CII Viewer | Displays CII XML used by ZUGFeRD / Factur-X |
| | XRechnung Viewer | Allows users to view XRechnung invoices |
| Conversion | CII → UBL Converter | Converts CII, used by Factur-X/ZUGFeRD, into UBL |
| | Factur-X Converter | Converts Factur-X between formats/profiles |
| | Factur-X → Peppol | Converts Factur-X into Peppol BIS |
| | ZUGFeRD Converter | Converts between ZUGFeRD profiles and works with PDF/A-3 + XML |
| | ZUGFeRD → Peppol | Converts ZUGFeRD into Peppol BIS 3.0 |
| | PDF → UBL | Extracts data from a PDF and creates UBL |
| | Peppol → PDF | Converts UBL/Peppol invoices into PDF |
| Extraction | ZUGFeRD XML Extractor | Extracts XML from ZUGFeRD PDFs |
| Identification | E-Invoice Format Detector | Detects the invoice format: UBL, CII, Factur-X, ZUGFeRD, XRechnung, etc. |
| Mapping | EN 16931 Mapper | Shows the mapping between EN 16931 business terms and UBL/CII |
| Structure | UBL Format Explorer | Allows users to explore the UBL 2.1 structure |
| Lookup | Peppol Radar / Participant Lookup | Checks whether a company is registered in Peppol and which document types it can receive |
| API | Peppol API | Automates invoice creation, validation, conversion, sending, and receiving |
| Network | Peppol Access Point | Sends and receives e-invoices through the Peppol network |
