# Tools

A quick reference to every tool used in the development workflow. Each entry includes a one-line description and a link to a short video to get you up to speed fast.

---

## Cursor

An AI-first code editor built on VS Code. Cursor lets you write, edit, and refactor code by chatting with an AI directly inside the editor — no copy-pasting from a browser required. This is the main tool Nika uses for frontend work.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=cursor+ai+code+editor+tutorial+beginners)

---

## Git

The version control system that tracks every change to your code. Every project at Fintom8 lives in a Git repository, and all collaboration happens through Git branches, commits, and pull requests.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=git+tutorial+for+beginners+short)

---

## GitHub Desktop

A visual desktop app for Git. Instead of typing Git commands in the terminal, GitHub Desktop lets you commit, push, pull, and manage branches through a simple graphical interface — ideal for day-to-day branch management.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=github+desktop+tutorial+beginners)

---

## FastAPI

A modern Python framework for building APIs. It is fast, lightweight, and generates interactive API documentation automatically. At Fintom8 it is used for backend services and endpoints.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=fastapi+tutorial+beginners+short)

---

## Next.js

A React-based framework for building web frontends. It handles routing, server-side rendering, and project structure out of the box, so you can focus on building UI instead of configuring tools. Used for all frontend work at Fintom8.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=nextjs+tutorial+beginners+short)

---

## Node.js

A JavaScript runtime that lets you run JavaScript on the server. Next.js runs on top of Node.js, so you need it installed locally to start the frontend development server.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=nodejs+tutorial+beginners+short)

---

## GCP Project

A Google Cloud Platform project is a container for all cloud resources — APIs, services, billing, and access permissions. Before deploying anything to GCP, you create a project and enable the services you need inside it.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=google+cloud+platform+create+project+tutorial)

---

## GCP Cloud Run

A serverless platform on GCP that runs containerised applications. You give it a Docker image, it handles scaling, networking, and HTTPS automatically. At Fintom8 it is used to deploy backend services without managing servers.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=gcp+cloud+run+tutorial+beginners)

---

## Python Environment

Python must be installed on your machine to run the FastAPI backend locally. At Fintom8 we use the **default system Python** — no virtual environments for local development. Make sure you know which Python version is active on your machine and how to install packages with `pip`.

[:material-youtube: Watch a short tutorial](https://www.youtube.com/results?search_query=python+installation+pip+beginners+tutorial)
